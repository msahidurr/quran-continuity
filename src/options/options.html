Quran Continuity

Rules for what happens when a surah finishes on Quran.com. Settings are stored only in this browser.

Playback rules

When a surah finishes, open the next surah and start it.

Playback stops after this surah finishes. If you start after it, auto-play also stops at the end of the surah you're on.

If the next surah starts at a different speed, set it back to the speed you were listening at.

Show a short message on the page when auto-play stops or fails.

When something fails

Extra attempts if the next surah fails to load or play (0–10).

1–60 seconds.

After the last attempt fails, auto-play stops and shows the error. It never retries endlessly.

Always on

  • Manual pause is never treated as a finished surah, and auto-play never resumes paused audio.
  • Manual navigation: when you play a different surah, auto-play follows it. Opening another page cancels a pending move.
  • Reciter: the extension never changes it. Quran.com's selected reciter is used.
  • Blocked playback: if Chrome blocks autoplay, you see an error and the extension waits for you to press Play.
